## Selected work

| Project | What's interesting about it |
|---|---|
| **[AGM-NLP](https://github.com/ShubhamHarkare/AGM-NLP)** | Attribution scores *fail* as a post-hoc predictor of cross-domain generalization failure — but the same signal works as a training-time regularizer. Benchmarked against DANN, IRM, Group DRO, and Fish across 12 transfer pairs, 8 seeds, bootstrap CIs. The negative result is the contribution. |
| **[CodeSearch-AI](https://github.com/ShubhamHarkare/CodeSearch-AI)** | Semantic search over code documentation — embedding retrieval with reranking, built around the vocabulary mismatch between how developers ask questions and how docs are written. |
| **[Attention-Play](https://github.com/ShubhamHarkare/Attention-Play)** | Transformer trained to generate song sequences from playlist structure. An early experiment in treating listening history as a sequence-modeling problem. |
| **[Code-Hive](https://github.com/ShubhamHarkare/Code-Hive)** | Real-time collaborative code editor. React + Socket.IO + CodeMirror, sandboxed multi-language execution, GitHub Actions CI/CD to Vercel and Render. |
